# 装甲风暴 · Tank Storm

一款用**纯 HTML5 Canvas + 原生 JavaScript** 编写的原创俯视角坦克射击游戏，无需任何依赖或构建工具，双击即可游玩。

## 玩法

- 控制你的坦克守住地图底部的**基地**，击毁所有来袭的敌方坦克即可过关。
- 基地被敌方炮弹击毁，或你的生命耗尽，游戏结束。
- 共 4 个关卡，地形包括可破坏的**砖墙**、坚不可摧的**钢板**、阻挡坦克却挡不住炮弹的**河流**，以及能隐藏行踪的**树林**。
- 击毁敌人会随机掉落道具：🛡️ 护盾、⭐ 火力升级、💣 清屏炸弹、❤ 额外生命、❄ 冰冻敌军。

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` 或 方向键 | 移动 |
| `空格` / `J` / `K` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `Enter` | 开始 / 重新开始 |

## 运行

直接用浏览器打开 `index.html` 即可：

```
tank battle/
├── index.html   # 游戏本体（自包含，无外部资源）
└── README.md
```

也可以在任意静态服务器下运行，例如：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 在线游玩（GitHub Pages）

将仓库部署为 GitHub Pages 后即可在线游玩：仓库 **Settings → Pages → Build and deployment → Branch 选择 `main` → Save**，稍后访问 `https://<用户名>.github.io/<仓库名>/`。

## 技术特点

- 原生 Canvas 2D 渲染，全部画面（坦克、地形、特效）均为程序绘制，无图片/音频资源。
- 音效由 Web Audio API 实时合成，不依赖任何音频文件。
- 完整游戏循环（`requestAnimationFrame`）、碰撞检测、敌人 AI、道具系统、粒子爆炸特效、最高分本地存储。
